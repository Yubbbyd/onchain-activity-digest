# Onchain Activity Digest

A Pharos Agent Center skill that summarizes the last 7 days of onchain activity for any wallet address — tokens sent/received, contracts interacted with, gas spent — returned as a clean, AI-narrable report.

---

## What This Skill Does

Given a wallet address, this skill:

- Fetches all transactions and ERC20 token transfers from the last 7 days on the Pharos network
- Categorizes activity into: tokens sent, tokens received, native transfers, and contract interactions
- Calculates total gas spent in native token and USD
- Flags notable events (large transfers, first-time contract interactions, contract deployments)
- Returns either a short plain-English narrative (summary mode) or a full structured JSON report (detailed mode)

This enables any AI agent to answer: *"What has this wallet been doing this week?"*

## Usage

### As a Skill (via Agent Center)

The skill accepts the following inputs:

| Parameter | Type   | Required | Default    | Description                          |
|-----------|--------|----------|------------|--------------------------------------|
| wallet    | string | Yes      | —          | The wallet address to analyze        |
| days      | number | No       | 7          | Number of days to look back          |
| format    | string | No       | "summary"  | "summary" or "detailed"              |

**Natural language triggers (examples):**
- *"Give me a weekly digest for wallet 0xABC...123"*
- *"What has 0xABC...123 been doing onchain this week?"*
- *"Summarize the last 7 days of activity for this wallet: 0xABC...123"*

---

### CLI Test Mode

To test the skill directly from the terminal:

```bash
node src/index.js
```

This runs a sample digest against a hardcoded test wallet and logs the result.

---

### Programmatic Usage

```js
import { generateDigest } from "./src/digest.js";

// Summary mode
const summary = await generateDigest("0xABC...123", 7, "summary");
console.log(summary.narrative);

// Detailed mode
const report = await generateDigest("0xABC...123", 7, "detailed");
console.log(report);
```

## Notes

- Gas USD conversion uses a static rate in `config.js`. Replace with a live price feed (e.g. CoinGecko API) for production use.
- Known contract labels in `addressLabel.js` are placeholders — extend with verified Pharos ecosystem addresses.
- The skill is read-only and does not sign or send any transactions.
- No private keys or sensitive data are required.
